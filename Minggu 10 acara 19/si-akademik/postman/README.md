# Postman – Acara 19
1. Import tiga file .json di folder ini (collection + environment Local + Staging).
2. Pilih Environment "Local" di pojok kanan atas.
3. Jalankan database/database.sql di phpMyAdmin (database si-akademik1).
4. Jalankan request pada folder Auth. Urutan disarankan: sukses -> field kosong -> email tidak valid -> duplikat.
5. Contoh response pada collection ditulis berdasarkan kode program; ganti dengan hasil asli
   (Send -> Save Response -> Save as example) sebagai bahan dokumentasi.
Catatan: ubah base_url pada environment Staging sesuai host staging Anda.
